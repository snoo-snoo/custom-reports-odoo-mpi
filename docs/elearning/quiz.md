# Abschlusstest – Company Report Branding

Bestehen ab 7 von 8 richtigen Antworten. In Odoo eLearning: Lektionstyp Quiz.

## 1. Wo stellen Sie das Corporate Design der PDFs ein?

- [ ] In jedem einzelnen Angebot unter „Optionen“
- [x] Einstellungen → Unternehmen → Ihre Firma → Reiter Report branding / Berichte (CI)
- [ ] Im Chatter der Rechnung
- [ ] Unter Apps → Aktualisieren

## 2. Wer darf den Reiter Berichte (CI) sehen?

- [x] Benutzer mit Administrations- / Einstellungsrechten
- [ ] Jeder Verkäufer
- [ ] Nur der Grafiker außerhalb von Odoo
- [ ] Kunden im Portal

## 3. Was passiert, wenn Sie ein Briefpapier-PDF hochladen, aber „Use letterhead on reports“ nicht aktivieren?

- [ ] Das Briefpapier erscheint trotzdem
- [x] Die Datei ist gespeichert, erscheint aber nicht auf den PDFs
- [ ] Odoo löscht die Datei
- [ ] Alle Berichte werden leer

## 4. Ihr Logo ist bereits auf dem Briefpapier. Welchen Logo-Modus wählen Sie?

- [ ] Company logo (standard)
- [x] Hide logo
- [ ] Custom report logo ohne Datei
- [ ] Gar nichts einstellen, Odoo erkennt das selbst

## 5. Sie wählen „Custom HTML footer“, lassen das Textfeld aber leer. Was passiert?

- [ ] Es wird die Standardfußzeile genommen
- [x] Odoo verhindert das Speichern und verlangt eine Fußzeile
- [ ] Die PDFs haben automatisch das Firmenlogo als Fußzeile
- [ ] Es ändert sich nichts

## 6. Wofür sind die Felder „above lines“ / „below lines“?

- [ ] Sie ersetzen die Positionstabelle
- [x] Feste Hinweistexte über bzw. unter der Positionstabelle, je Belegart
- [ ] Sie ändern die MwSt.
- [ ] Sie sind nur für den internen Chatter

## 7. Google-Schrift erscheint nicht im PDF. Was prüfen Sie zuerst?

- [ ] Ob der Kunde online ist
- [x] Ob der Schriftname genau stimmt und der Server das Internet erreichen kann – sonst Schriftdatei hochladen
- [ ] Ob der Drucker eingeschaltet ist
- [ ] Ob Studio installiert ist

## 8. Gilt das Branding pro Benutzer?

- [ ] Ja, jeder Benutzer hat sein eigenes Briefpapier
- [x] Nein, es gilt pro Unternehmen (Firma in Odoo)
- [ ] Nur für den Administrator
- [ ] Nur für archivierte Firmen
