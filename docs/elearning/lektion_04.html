Schriften

Es gibt zwei getrennte Einstellungen: Heading (Überschriften wie „Invoice“) und Body (restlicher Text).

Drei Quellen stehen jeweils zur Wahl:

  1. Odoo layout / theme – nichts Extra, Schrift wie im Dokumentlayout.
  2. Google Font – Namen eintragen, z. B. Roboto oder Open Sans (genau so wie auf fonts.google.com). Der Server braucht Internetzugang.
  3. Uploaded font file – TTF, OTF, WOFF oder WOFF2 hochladen. Lizenz zur Einbettung in Kunden-PDFs vorher klären.

Ohne Namen bei Google Font oder ohne Datei beim Upload ändert sich optisch nichts. Danach immer Save und ein PDF zur Probe öffnen.
