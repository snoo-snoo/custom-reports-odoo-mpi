# Company Report Branding – Anwendertraining (E-Learning)

Dieses Verzeichnis enthält den Kursstoff, den Sie in der Odoo-App **eLearning**
veröffentlichen können. Zielgruppe: Allgemeine Anwender ohne Technikwissen.

## Lieferumfang

| Datei | Verwendung in Odoo eLearning |
| --- | --- |
| `../user_guide/Company_Report_Branding_Benutzerhandbuch.pdf` | Lektion Typ **Dokument** (Download erlauben) |
| `../user_guide/videos/*.mp4` | Lektionen Typ **Video** (URL) oder Zusatzdatei zum Download |
| `lektion_01.html` … `lektion_08.html` | Lektionen Typ **Artikel** |
| `quiz.md` | Abschlusstest (von Hand oder über das Addon) |
| `kursstruktur.md` | Abschnitte und Reihenfolge |

## Schnellstart

**Variante A – Addon:** Modul `company_report_branding_elearning` installieren
(App eLearning muss vorher installiert sein). Der Kurs wird angelegt.

**Variante B – manuell:** eLearning → Neu → die Struktur aus `kursstruktur.md`
nachbauen und Dateien hochladen. Schritt-für-Schritt steht im Benutzerhandbuch,
Kapitel 13.

## Video-Hinweis

Odoo eLearning spielt Videos in der Regel über YouTube, Vimeo oder Google Drive.
Die MP4-Dateien in diesem Repository sind zum **Herunterladen** und optionalen
Hochladen auf eine dieser Plattformen gedacht. Hängen Sie sie außerdem als
„Additional Resource“ an die passende Lektion, damit Teilnehmende offline üben können.
