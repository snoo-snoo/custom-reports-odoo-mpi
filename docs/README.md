## E-Learning in Odoo

Zwei Wege:

1. **Addon installieren:** `company_report_branding_elearning`  
   (App eLearning muss vorher installiert sein). Legt den Kurs
   „Company Report Branding – Anwendertraining“ mit Artikeln, PDF, Videos und Quiz an.
2. **Kurs von Hand:** Anleitung in [elearning/README.md](elearning/README.md)
   und im Handbuch Kapitel 13.
