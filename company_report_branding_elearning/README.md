eLearning-Kurs für **Company Report Branding** (Odoo 19).

## Was die Installation macht

Nach Installation der App **eLearning** und dieses Addons erscheint der Kurs

**Company Report Branding – Anwendertraining**

mit Abschnitten, Artikeln, dem PDF-Handbuch zum Download, drei Videos als
Zusatzdateien und einem Abschlusstest.

## Installation

1. App **eLearning** (`website_slides`) installieren.
2. Dieses Addon `company_report_branding_elearning` in den Addons-Pfad legen
   (im selben Repository wie `company_report_branding`).
3. App-Liste aktualisieren und **Company Report Branding eLearning** installieren.
4. Website / eLearning öffnen – der Kurs ist für angemeldete Benutzer sichtbar.

## Ohne Addon (manuell)

Siehe `docs/elearning/README.md` und Kapitel 13 im Benutzerhandbuch.
Die PDF- und Videodateien liegen unter `docs/user_guide/`.
