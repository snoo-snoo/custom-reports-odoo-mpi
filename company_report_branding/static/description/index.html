Company Report Branding

Give every company its own PDF identity: letterhead, fonts, logo, footer, and HTML notes around document lines.

Odoo 19 · Multicompany · Odoo.sh compatible · LGPL-3

Company Report Branding adds a Report branding tab on Settings → Companies (administrators only). One configuration drives the usual external PDF layouts — quotations, delivery slips, purchase orders, customer invoices, credit notes, and vendor documents — without forking each report.

Settings live on res.company, so each company in a multicompany database can use its own stationery, typefaces, and legal footer.

Features

Letterhead PDF

Upload your A4 stationery. The first page is rasterized as the report background. Content margins (mm) keep body text clear of artwork.

Per-report switches

Turn branding on or off for sales, deliveries, purchases, invoices, credit notes, vendor bills, or all other external PDFs.

Heading and body fonts

Keep the Odoo layout default, pick a Google Font family, or upload WOFF2/TTF. Uploaded fonts are served through a token URL for PDF rendering.

Logo modes

Use the standard company logo, hide it when the letterhead already contains it, or upload a logo used only on reports.

Footer modes

Standard Odoo footer text, custom translatable HTML, or no footer text when the stationery already carries legal lines.

HTML near line tables

Optional blocks above and below product lines, separately for quotations, deliveries, purchase orders, invoices, credit notes, and vendor documents.

Configuration

  1. Install the module (and PyMuPDF via the repository root requirements.txt on Odoo.sh).
  2. Open Settings → Companies as a user in Settings / Administration.
  3. Open the company and switch to the Report branding tab.
  4. Select the document types that should receive branding.
  5. Upload the letterhead PDF, enable Use letterhead on reports, and set margins.
  6. Choose fonts, logo mode, footer mode, and optional HTML near line tables.
  7. Print a quotation or invoice to verify that text stays inside the artwork.

Compatibility

  • Odoo 19.0 Community and Enterprise.
  • Depends on web, sale, stock, purchase, and account.
  • Applies to Odoo external layouts: Light, Striped, Boxed, Bold, Folder, Wave, Bubble.
  • German UI translation is included (i18n/de.po); English is the default in code.

Notes

  • Letterhead v1 uses a raster background of the first PDF page. Vector PDF merge is not included.
  • Google Fonts need outbound HTTPS from the PDF worker to fonts.googleapis.com unless you upload font files.
  • With footer mode “no footer text”, layout-specific page lines may still appear depending on the theme.
  • PyMuPDF is optional at runtime; without it the letterhead PNG is not generated.
